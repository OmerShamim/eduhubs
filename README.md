# Eduhubs

This repository is a simple demonstration project used for learning Git and version control concepts. It is not a full Java application or a production software project.

## Purpose

The files in this repository are intentionally minimal and are used to demonstrate common Git workflows such as:

- basic version control usage
- editing and modifying tracked files
- stash operations
- cherry-pick
- hotfixes
- multi-developer changes
- demonstration of version history and collaborative workflows

## Repository structure

At the root of the repository, you will find text-based Java-like files such as:

- `1.java`
- `2.java`
- `audio.java`
- `video.java`

These files do not contain full Java classes or real application logic. They are mostly short notes and examples used during Git demos.

## What this repository is not

This is not:

- a web application
- a mobile app
- a backend service
- a Java project with classes and methods
- a production-ready system

## Summary

The repository acts as a lightweight training example for understanding how Git tracks changes over time and how developers collaborate in a version-controlled environment.

It is best viewed as a Git practice repository rather than an application codebase.
